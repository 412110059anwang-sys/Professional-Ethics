# 🌿 專業倫理 × LLM Wiki 互動學習知識庫

> **「其實沒有很複雜！」** —— 將生硬的道德哲學與專業倫理講義，透過 **Karpathy LLM Wiki** 結構化編譯，並轉化為溫潤手寫風、好讀又好玩的互動式網頁簡報。

## 📂 核心流程一覽（對應專案架構圖）

1. **`CLAUDE.md` / `AGENTS.md`**：定義 AI 整理知識與生成簡報的規範。
2. **`raw/` & `wiki/`**：存放原始課程講義（`Moral Theories and a Model for Moral Decision Making`）與編譯後的雙向連結知識網。
3. **`ideas/`（整理想法）**：完全根據 Wiki 內容產出的主題研究筆記（文末附外部延伸待讀清單）。
4. **`slide_notes/`（簡報逐頁稿）**：將筆記濃縮為每頁 4 大元素的視覺腳本。
5. **`assets/`（我們的小插圖）**：溫潤手繪感 SVG 貼圖素材。
6. **`presentation/`（最終的簡報） & `index.html`**：奶茶色系手寫貼圖風 HTML 簡報，內建 **`[💡 補充 / 更多..]`** 展開抽屜與 **`💭 想一想`** 互動提問框。
